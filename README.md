# IEOR 4578 - Project 2
Time series analysis of the [Online Retail II](https://archive.ics.uci.edu/dataset/502/online+retail+ii) dataset.

This project investigates a range of approaches for analyzing and forecasting grouped time series data, including:
- Novel LLM-based clustering techniques, alongside traditional clustering methods, to identify patterns in the data
- Classical machine learning forecasting models for grouped time series
- State-of-the-art deep learning methods such as Temporal Fusion Transformer (TFT) and DeepAR

A comparative evaluation of all approaches to assess performance and interpretability
